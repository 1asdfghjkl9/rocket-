## 已实现功能

### 天体系统
- **太阳系22个天体**：太阳、水星、金星、地球、月球、火星（火卫一/二）、木星（木卫一/二/三/四）、土星（土卫六/五/八）、天王星、海王星（海卫一）、冥王星（冥卫一）、谷神星
- **23个附近恒星系统**：比邻星、半人马座α A/B、巴纳德星、天狼星 A/B、鲸鱼座τ等
- **程序化行星纹理**：海洋型（地球）、气态巨行星（木星/土星）、冰世界、岩质、熔岩、恒星，使用Canvas + 分形噪声生成
- **土星环 + 大气层光晕**
- **8000颗恒星背景**

### 物理引擎
- **N体引力系统**：Velocity Verlet数值积分，所有天体互相施加引力
- **轨道力学**：开普勒方程求解、轨道要素计算（半长轴/偏心率/倾角/近地点/远地点/周期）
- **轨迹预测**：200步前向预测，考虑多体引力扰动
- **物理子步长自适应**：高时间加速下自动拆分子步，最大4000步/帧

### 火箭系统
- 推力/比冲(Isp)/燃料消耗率/质量变化完整模型
- 推重比(TWR)和剩余Delta-V实时计算
- 姿态控制（俯仰/偏航/滚转，四元数旋转）
- 分级分离
- 节流阀控制（0-100%）

### 时间加速
- 11级：1x → 2x → 5x → 10x → 50x → 100x → 1000x → 5000x → 10000x → 50000x → 100000x

### 曲率引擎
- 1000倍光速超光速移动
- 30秒星际跳跃
- 需1000科技点解锁
- 靠近恒星时自动充能
- 星图选择目标星系

### 科研基地
- 部署在任意天体表面（需低空接近）
- 持续产出科技点
- 跟随行星运动
- 可升级（科研效率×1.5）

### UI/HUD
- 速度/高度/质量/推力/TWR/Delta-V显示
- 轨道参数面板（Ap/Pe/偏心率/倾角/周期）
- Canvas绘制的Navball姿态指示器
- 燃油/节流阀进度条
- 科技点/曲率引擎状态
- 游戏时间显示
- 星图选择界面
- 通知提示系统
- 帮助界面

### 角色模型
- 人类宇航员模型（替代KSP小绿人）：身体+头盔+四肢+背包

## 技术架构
- **引擎**：Three.js 0.170.0
- **构建**：esbuild打包（单文件bundle.js, 942KB）
- **物理**：自研N体引力引擎（Velocity Verlet积分）
- **渲染**：程序化生成所有3D资产（无外部模型文件）
- **缩放系统**：DIST_SCALE=1e-9（距离）, BODY_SIZE_SCALE=1e-6（天体大小）, SIZE_BOOST=30（可见性）

## 文件结构
```
ksp-game/
├── index.html          # HTML入口（内联CSS）
├── dist/bundle.js      # esbuild打包的完整游戏（942KB）
├── vendor/three.module.js  # Three.js库
├── src/
│   ├── index.ts        # 入口
│   └── game/
│       ├── data.ts     # 天体数据/星表/物理常数
│       ├── physics.ts  # N体引力引擎/轨道力学
│       ├── render.ts   # 程序化纹理/3D模型工厂
│       ├── entities.ts # 火箭/科研基地/曲率引擎/宇航员
│       ├── ui.ts       # HUD/Navball/星图/通知
│       └── game.ts     # 主游戏引擎（集成所有系统）
└── scripts/            # 构建/启动/验证脚本
```
